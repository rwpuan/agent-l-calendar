Privacy policy

Last updated: 16 October 2026

Agent L is a private assistant used by one person, its owner. It is not offered to the public.

What it accesses

With the Google Calendar permission, Agent L reads and changes events on its own Google Calendar ("Agent L"). It asks for no other Google data: no email, contacts, files or other calendars.

How the data is used

  • Calendar data is used only to answer its owner's questions and to make changes the owner has approved.
  • It is not sold, shared with anyone else, used for advertising, or used to train AI models.
  • The sign-in token is kept on the owner's own computer, readable only by the account that runs Agent L.

Google API Services User Data Policy

Agent L's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. The token on the owner's computer is then deleted.
